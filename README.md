# 跨境消费多模态智能导购 Agent

珠澳商品搜索、图片识别、公开价格比较与购物路线网页，暂用「过关 GoCross」名称。Node.js 20 以上，无第三方运行依赖。

## 团队在线预览

[打开共享网页](https://super-duper-robot-jrqrj964x76qh5rxq-5173.app.github.dev/)

页面运行在共享 Codespace，5173 端口已按项目负责人确认设为公开；Codespace 停止或休眠时链接暂不可用。当前可预览界面、查询中免商品和使用地图，云端识图尚未启用。本机密钥和电商登录会话不会随代码上传。

## 启动

运行 `npm start` 或双击 `start.cmd`，打开 http://127.0.0.1:5173/ 。仅本机访问可先设 `$env:HOST='127.0.0.1'`，默认 HOST 为 0.0.0.0。

智谱密钥存于本机 `.env` 的 `ZHIPU_API_KEY=`，参考 `.env.example`，禁止提交/分享。密钥仅由后端读取，视觉接口仅本机可用，服务器不保存原图。

## 搜索与报价

团队共享代码及 Codespaces 预览步骤见 [团队预览说明](docs/team-preview.md)。转发端口为 5173；预览运行在云端，与本机使用同一套源码，不自动同步本机密钥和登录状态。

- 任意品牌、商品或型号均可查询，无本地种类白名单。SK II、SK-II、SKII、sk 2 统一检索，中文短品类也可搜索。
- 上传 JPG、PNG、WebP（最多 8 MB）后自动发至智谱，识别主商品并搜索，无核对步骤；保留可编辑检索词。广告赠品容量和广告价不得当成主商品规格与当前报价。
- [中免澳门官方商城](https://glp.cdfgmo.com/) 公开只读接口提供真实商品字段、图文链接、规格、SKU/条码、价格与抓取时间。首页取官网首批六件，搜索可分页，不限这六件。
- 首页每件商品只显示一条已获取报价及线上/线下渠道；多条可比报价时显示其中最低者。「比价详情」展示全部已取得报价、其他平台查询状态和价格说明。
- 比较要求同款、同规格；容量、件数、系列冲突不合并。区间价、缺失价、登录专享价不作为确定最低价。没有线下门店价格，官网报价标为线上。
- 国内平台改为每日快照：首次搜索尝试采集，此后同一平台/关键词每 24 小时最多尝试一次；页面刷新不绕过间隔。已有搜索关键词在服务运行时每五分钟检查是否到期；关机期间不执行，重启后补查到期项。最多跟踪 60 个平台/关键词组合，并非全站爬取。
- 国内价格、公开详情、来源链接、真实采集时间写入 `.runtime/daily-prices.json`，重启继续复用。失败也等待下一周期，保留旧记录但不更改其时间；超过 24 小时的价格不参加最低价。中免保持查询时更新，两分钟前的中免报价不参加最低价；汇率仍每 30 分钟更新。
- 页面显示“最近采集价”和北京时间，最低价仅指已采集到的同款同规格有效报价。运费、税费、资格优惠及实际支付价以平台结算为准。
- 识图不再用同品牌其他系列凑结果，已知容量/件数冲突会剔除；中免成功查询但没有匹配商品时，提示可能需到线上第三方平台购买，并提供京东/淘宝/天猫搜索入口。入口不代表已核实在售或库存；未取到价格时不生成商品报价。非商品或只有品牌时不启动商城采集，官网故障不显示“无匹配”购买建议。

## 国内平台的实际边界

`commerce.mjs` 提供公开搜索页采集与标准 JSON-LD 商品价格/详情解析，`daily-market.mjs` 提供持久化每日调度。仅接收相应官方商品域名上的正数人民币固定价，失败不填充报价。**尚未成功取得国内三平台的有效商品价，每日调度完成不等于这些平台取价已打通。**

2026-10-16 既往实测：京东跳转登录验证；淘宝、天猫普通 HTTP 只返回动态外壳。随后淘宝浏览器访问被工具站点安全策略禁止，未换渠道绕过。详情的「平台搜索」供用户自行打开，不是取价证据。当前真实报价仍以中免澳门为主，未接入付费服务或联盟凭据。

如环境不允许某来源，可设置 `DISABLED_MARKET_PLATFORMS=taobao,tmall` 停止自动请求，仍保留手动查看链接。GitHub 源码和服务核验见 [调研记录](docs/price-sources.md)。

## 汇率、识图、地图

- [中国银行外汇牌价](https://www.boc.cn/sourcedb/whpj/)：MOP/HKD 现汇卖出价按 100 外币单位换算，每三十分钟后台刷新，失败保留上次值及状态。人民币为参考换算，非结算承诺。
- 免费视觉模型 `glm-4.6v-flash`，繁忙/超时/无效结果时仅回退一次 `glm-4v-flash`，未启用付费型号。无法保证每次识别成功，失败可直接输入商品名。
- 免费 OpenStreetMap 嵌入和 Google Maps 路线 URL，无地图 key。只在已收录的中免上葡京、新八佰伴、四季名店三处比较直线距离；真实路程/时间在外部地图查看。定位仅本页排序，打开路线才传起点给地图平台；库存未接入。
- 已删除模拟商品、模拟报价/评论、预设场景、旧决策引擎和演示入口。用户原始稿只在 references/ 留作追溯，不参与运行。

## 验证与接口

`npm test` 覆盖归一化搜索、相关性、同款规格、价格解析/排序/时效、并发合并、官方数据和汇率、地图、视觉校验与本机密钥边界。注入响应测试与现场取价验证分开记录。

接口：`GET /api/products/home`、`/api/products/search?q=关键词&page=1`、`/api/products/match?item=识别JSON`、`/api/products/compare?id=p商品编号`、`/api/products/detail?id=p商品编号`、`/api/rates`、`/api/catalogue`。搜索/匹配/比价支持 `fresh=1`；`POST /api/vision/recognise` 提供本机识图。

未更新既有 WorkBuddy 线上版本。本地服务已重新运行；具体网页验证与未解决来源限制见 `logs/2026-10-16.md`，不把注入数据测试当成平台真实取价成功。
