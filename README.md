# 跨境消费多模态智能导购 Agent

过关 GoCross 是面向珠海、澳门购物行程的消费助手，由 CIA 小组协作开发。文字和单张商品图片进入同一个购物任务，查询已有数据后给出购买建议、依据、待核实事项和后续问题。当前源码使用智谱免费文字模型优先、DeepSeek 兜底，图片先经智谱视觉识别。首页采用连续对话和商品卡。Node.js 20 以上，无第三方运行依赖。

界面提供历史记录、新对话、语言、图片与发送；处理中发送替换为停止。桌面以澳门全景衬托一体购物工作区，聊天下方衔接门店地图和地点选择；手机采用澳门街景，保留原有两张地点照片。Agent 的到店计划同步地图范围和顺序，线上购买项不进入路线。简短文字可配合匹配商品的图片/规格/报价卡，多站行程提供导航，依据和补充说明可展开查看。

澳门日落天际线融入桌面整页，手机使用议事亭前地街景以适配窄幅裁切；中性白购物区确保价格、问题和地图文字清晰。设计使用从GitHub安装的Anthropic frontend-design技能，具体说明见 docs/macau-design-revision.md。图片复用用户源码包的既有素材，不作为门店实拍或库存证据。

## 启动与密钥

运行 `npm start` 或双击 `start.cmd`，打开 <http://127.0.0.1:5173/>。默认监听 `0.0.0.0`，仅本机访问可设置 `HOST=127.0.0.1`。

在已有 `.env` 中添加下面一行，不要覆盖原来的其他配置：

```dotenv
DEEPSEEK_API_KEY=你的DeepSeek官方密钥
```

也可以配置 `ZHIPU_API_KEY`，用于智谱免费文字路由及商品图片识别；文字任务至少需要上述两项中的一项，图片识别需要智谱密钥，Search/Fetch 工具需要 DeepSeek 密钥。支持同名环境变量；模型密钥按请求读取，修改密钥后无需重启。密钥不进入前端、返回数据、Git 或日志。不要把 `.env` 发到聊天、提交仓库或放在 `public/`；只能作为私有服务端配置交给已授权的部署环境。`.env.example` 只有配置名称和公开来源示例。旧 `/api/vision` 接口保留兼容。

## WorkBuddy 部署与同源保护

WorkBuddy 的单端口 Node 服务用 `npm start` 启动，平台注入 `PORT` / `HOST`。它不是 Codespaces；在部署目录的私有 `.env` 中配置：

```dotenv
PUBLIC_ORIGIN=https://gocross-shopping-guide.app.workbuddy.host
```

`PUBLIC_ORIGIN` 在服务启动时读取，修改后须重启/重新部署。优先使用非空环境变量，否则读取与模型密钥相同的 `.env` 解析器，支持单/双引号和行末注释。平台不能设置自定义环境变量时，WorkBuddy 可将已授权的私有 `.env` 随服务端项目目录上传；密钥留在服务器，静态目录和状态接口均不返回它。

支持逗号分隔的多个来源，例如 `https://gocross-shopping-guide.app.workbuddy.host,https://team.example:8443`。每项必须是小写的 `https://host[:port]`，不能有路径、尾斜杠、通配符、用户信息、查询或片段；无效项忽略，全无效则不启用公开来源。显式非空环境配置即使无效也不会回退到文件中的其他来源。

公开来源访问 `/api/agent/*`、`/api/vision/*` 时，浏览器 `Origin` 必须与名单中某项完全一致，且 `Sec-Fetch-Site` 必须是 `same-origin` 或 `none`；公开 POST 必须带 `Origin`。反向代理改写 `Host` 不影响授权。不新增宽松 CORS 头；页面直接调用同源 API。已有 localhost 和 Codespaces 自动推导/隧道规则保留，两类配置可同时启用。无公开配置时远程仍拒绝访问。

公开来源已配置时，只有两个只读状态 GET `/api/agent/status`、`/api/vision/status` 可以省略 `Origin`，且响应仍只有 `{configured, model}`。明确的外站 Origin 或跨站元数据仍会拒绝。

**任何拿到链接的人都共享服务端已配置模型账号的额度。Origin 检查阻止跨站网页嵌入/调用，不限制持链接用户的使用，也不构成登录认证。** 不要将其当作费用上限或私人访问控制。现有并发、频率及图片大小限制保持不变。

## 一份清单怎样处理

例如用户需要 A/B/C：逐项检索同款同规格报价，比较线上与实际门店报价。B 若在已核实的可比报价中线上更便宜，就说明线上渠道，并从到店采购路线排除 B；A/C 的到店采购按门店合并，再生成路线。未确定购买方式的商品单独说明，不强行安排门店。

- `search_products` 复用真实商品及国内平台每日采集服务；每次最多交给模型 6 件候选。
- `search_web` / `fetch_web_page` 使用同一个 DeepSeek Key 调用 10 月 17 日开放的独立 Search/Fetch API；查找受限官方来源及商品链接，并读取本轮发现的允许页面。每轮最多合计 3 次，网页正文最多 6500 字符；摘要/网页文字不直接进入数值比价，不代理抓取京东/淘宝/天猫登录或风控页面。实际测试 Search 与澳门海关页面 Fetch 成功；费用与研究见 [deepseek-research.md](docs/deepseek-research.md)。
- `compare_purchase_channels` 分开比较线上和实际线下报价。中免**官网报价属于线上**，不能当门店报价。缺少任一渠道时返回 `unresolved`，不生成“线上省多少”的结论。
- `get_exchange_rates` 读取中国银行 MOP/HKD 参考牌价与时间；每半小时后台刷新，失败时标记旧数据。
- `calculate_cost` 只用本轮工具返回的有效报价 ID 计算件数与参考成本，另加用户提供的交通费；不虚构税费。未知交通费和税费不计入时必须说明。
- `find_stores` 读取已收录的 12 个购物目的地；品牌专柜覆盖及来源见 [batch-2.md](docs/batch-2.md)。没有门店库存数据。
- `plan_shopping_route` 接收逐项购买方式，只有 `in_store` 项进入路线；`online` / `unresolved` 项排除，同店合并。坐标已知时在最多 3 个地点中枚举直线距离顺序，否则保留建议顺序；不声称最短道路路线。步行/驾车生成多站 Google Maps 链接，公交提供逐段链接。实际交通时间、道路与费用交给外部地图。

门店来源、导航和实际工具执行记录在回答中提供；导航链接直接可见，其他来源可展开。右上角语言开关同时切换界面和已有 AI 回答。模型一次返回中英两份受限答案，切换不重复调用模型。用户原始输入保留原文。

图片选择/拖放后自动发送至服务端，先经智谱视觉识别，再与输入框中的文字共同进入购物任务。只允许有效 JPG/PNG/WebP，最多 8 MB。服务器不保存原图；完成的对话（含上传图片、中英回答、商品卡和路线）保存在当前站点的浏览器 IndexedDB，最多发送最近 10 条历史文字作为模型需求上下文。停止会取消前端等待及后续模型请求，已经发出的供应商调用可能已计费。

顶部“历史记录”可按用户/AI文字或商品名称搜索，按最近更新排序；点击记录可恢复地图及继续追问，刷新可恢复上次对话。“新对话”开始空白对话，保留此前已保存的记录。历史内容会提示旧报价需重新核实；打开历史不会重新调用模型或查询价格。只保存已完成的交流，不保存未发送草稿；存储失败时提示并保留当前页面的回复。

历史只属于同一浏览器/站点（含端口），不会上传公共服务器，也不跨设备同步。清除浏览器站点数据会移除记录；新增功能前已关闭、仅存内存的对话不能恢复。历史实现与验证见 `docs/conversation-history.md`。

图片小字容量实测存在误读，因此图片只按可读品牌/品名/品类自动检索，原图容量保留未核实；用户文字或真实商品候选的规格分别使用，不把候选容量当作原图容量。

## 已有数据与实际边界

[中免澳门官方商城](https://glp.cdfgmo.com/) 提供真实公开商品字段、规格、SKU、价格和时间；[中国银行](https://www.boc.cn/sourcedb/whpj/)提供参考汇率。报价只在同款同规格且未过期时参与比较：中免 2 分钟，国内平台 24 小时。没有全网最低价或到店有货承诺。

**国内京东/淘宝/天猫有效商品价格仍未打通，澳门实际门店报价与库存也未接入。** 已有每日快照调度和公开 JSON-LD 解析不等于取价成功；当前不能实际证明“B 的线上价已比澳门门店便宜”。这一业务规则和路线筛选已有离线测试，但必须有两端的真实数据才能作出这样的实际建议。历史登录/风控与来源限制见 [price-sources.md](docs/price-sources.md)，不绕过验证，不使用样例价补位。`DISABLED_MARKET_PLATFORMS=taobao,tmall` 可停用对应采集。

已接入带来源与核对日期的海关政策规则表，仍未接入正式税费计算；规则表不是实时政策查询，AI 不可给出未经查证的税率、额度或放行保证。门店扩展、方案数量/总额、历史选择删除及重试等本次同步功能见 [batch-2.md](docs/batch-2.md)。比赛完整规则及指定平台尚未获得，当前改造不代表已满足提交要求。

## 输出与调用边界

当前文字路由优先尝试智谱 `glm-4-flash`、`glm-4.7-flash`、`glm-4.5-flash`，DeepSeek `deepseek-flash` 作为兜底；路线任务优先使用 DeepSeek。工具规划与最终回答的预算、型号冷却及结构无效后的一次重试以 `agent.mjs` 为准；整轮 150 秒截止。长清单超预算时说明未完成部分。

主回答限制为中文 240 / 英文 520 字符；追问为 80 / 160 字符。依据/下一步各最多一条、120 / 180 字符，默认折叠。模糊需求通过 `ask_follow_up` 先问最多两个相关关键细节，本轮不执行外部检索；回复后利用对话历史继续处理完整清单。明确型号的查价无需强制预算，已选门店的导航无需再问规格。

后端检查中英 JSON 字段、长度、本轮来源和商品 ID。最多三张商品卡由真实商品数据生成，图片只允许既有官网图片域；报价必须在有效期内，只有统一币种换算齐全时才排名，不声称全网最低。不接受模型提供任意网址/HTML，页面按文本渲染；来源和导航由服务端工具建立。提示词约束不能保证模型永不出错，结构验证不等于事实验证。OSM 嵌入显示门店范围和首站标记；完整道路导航由 Google Maps 打开。

沿用本机/Codespaces 同源保护并支持显式 `PUBLIC_ORIGIN`，单服务同时 1 个任务、每分钟最多 10 个 Agent 请求。公开预览访客共享同一账号的模型额度；同源检查不等于身份认证或费用上限。未经配置时返回清楚提示，不回退假回答。

## 验证与接口

`npm test` 覆盖原有检索、同款匹配、报价、缓存、汇率、视觉及同源保护，新增 Agent 工具链、输出校验、图片直传、成本计算和线上商品排除路线。模型及线下报价注入测试与真实供应商调用严格区分。

新版：`GET /api/agent/status` 仅返回配置状态和模型名；`POST /api/agent/message` 接受 `{message, language:"zh"|"en", image?:dataURL, history?:[{role,content}]}`，只允许 user/assistant 历史，不接受外部 system/tool 消息。

旧接口保留：`/api/products/home`、`/api/products/search`、`/api/products/match`、`/api/products/compare`、`/api/products/detail`、`/api/rates`、`/api/catalogue`、`/api/vision/status`、`/api/vision/recognise`。后台商品采集可用 `npm run crawl:products` 手动执行。
