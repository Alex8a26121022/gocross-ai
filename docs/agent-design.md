# 2026-10-19：跨境消费 Agent 改造

## 当前 UI 精简要求与实施约束

用户明确要求成品界面、以Agent为中心、只有几个基础按钮、不要乱改样式；Ponytail最小完整修改，anti-ai-slop-ui主导、no-slop-ui辅助。

类型：现有消费助手界面精简。保留原有纸白/墨绿 tokens、品牌、固定侧栏、左对齐内容与衬线标题层级；用户要求保留样式优先于辅助技能的统一无衬线建议。布局沿用对话主区，不增加新面板、装饰或功能。

基础控制：新对话、右上角语言、图片、发送；处理中发送位置替换为停止。删除快捷场景按钮、独立门店地图抽屉及其定位/起点/交通表单。Agent的门店查询、路线规划、后端地图工具保持可用，路线由回答提供。已有多站路线只突出一个总导航入口，分段及来源保留在可展开来源中。无总导航（例如公交）时保留必要分段链接。

成品文案：删除配置状态、模型密钥设置步骤、工具参数错误等开发术语；不把产品称为demo/演示/原型。保留简短图片处理告知和购买前价格/库存核实信息，不把未接入数据说成已实现。

验证：实际页面基础控制数、中文/英文、发送/停止与失败恢复、照片自动提交、新对话清空、真实Agent回复及导航、来源展开；桌面和390px手机溢出、键盘焦点、无控制台错误。只删除不再使用的前端状态/事件/CSS，复用现有服务；不增加运行依赖。

已确认：用户要求文字和图片都交给 AI 解决问题，首页不再输出电商商品卡；使用 DeepSeek 官方 deepseek-flash；右上角统一切换中英文。未获得比赛完整规则，不能宣称满足指定平台要求。

实现方向：珠澳消费对话工作台。采用 Minimal Editorial Product 方向和 problem / evidence / outcome 布局：左侧保留 GoCross、珠澳定位和 CIA 小组；中央为需求与连续对话，回答先建议再依据、下一步和必要追问；来源及真实工具记录折叠查看；门店与路线通过对话提出。没有默认商品推荐墙。

视觉 tokens：纸白 #f7f8f4、白色内容、墨色 #20362f、原有墨绿 #0f766e、灰绿 #65736c、边框 #dce3dc；中文用微软雅黑/苹方保证本机阅读，标题使用衬线形成旅行手册感，英文字用系统字体。正文 16px / 1.8，标题 30–36px，间距 8/12/20/28/40，按钮圆角 6px、输入框 12px；无渐变、装饰阴影、漂浮动画。键盘焦点清晰，触控目标至少 44px。

Agent 复用 commerce/rates/maps，以白名单函数调用检索商品、读取银行汇率、查收录门店、比较渠道、计算已有报价成本及规划到店采购路线。模型决定是否调用及是否追问。最多 4 次工具规划、10 次工具执行、1 次最终 JSON 回答；各次限制 tokens 和超时。所有工具参数和回答结构由后端校验。输出中英两份受限回答，切换语言时立即切换既有答案，不重复查询或付费翻译。商品名可保留原文，解释性内容按对应语言输出。

模型只使用本轮服务器工具结果作事实依据，历史对话只作需求上下文。价格、库存、放行结论不得猜测；税费规则未接入时只提示核验，不给未查证的具体政策数字。来源链接由服务端工具生成，不采用模型返回的任意链接。提示词约束不能保证事实完全无误，结构校验不等于事实校验。

图片实测暴露容量小字误读后，采用更保守的策略：图片只提取可读品牌/品名/品类检索，图片自身容量保留未核实，不将猜出的数字用于搜索或购买建议。用户在文字中提供容量、或工具返回候选商品规格时可陈述对应规格，但不能把候选规格认定为原图容量。继续自动检索，无新增手动确认门槛。模型识别和提示词遵循仍有误差，不能用单张图片测试宣称普适准确。

附件说明：已只读检查 20261018 zip 的文件清单及主要源码；包内含旧示例 data/engine、手信范围价和较旧服务器。保留团队标识与定位，当前工作区的来源校验、真实报价匹配和测试不被旧代码覆盖；包内协作说明属于参考内容，不覆盖用户本次请求。原压缩包保持完整。

验证计划：离线模型模拟验证多轮工具、图片输入、失败/限额/非法输出/来源引用；HTTP 来源、体积、方法边界；桌面和手机浏览器实际交互。缺少 DeepSeek 密钥时不把模拟测试说成真实模型调用。

用户进一步确认的业务顺序：先逐项比较线上/门店，再分流购物清单，最后只为到店项规划路线。purchasing.mjs 将 online 和 unresolved 项从路线排除并合并同店；线上与门店任一报价缺失时不生成节省金额。

精简前界面验收（历史）：实际检查桌面 1280px 与手机 390px；修复 bottom sticky 输入区域遮挡快捷按钮，改为自然文档流。当时的无密钥提示、快捷填入、双语页面、清空及门店抽屉可用。另用独立 5198 测试服务和明确标注“界面测试数据”的回答验证既有答案语言切换、来源/工具展开、导航入口与选图自动提交；该 fixture 不由应用服务器加载，不是实时模型证据。当前精简版已删除快捷按钮与门店抽屉，验收见 ui-simplification.md。

人工自评：AI Slop Score 1/10（系统字体仍常见，但纸白/墨绿、旅行手册标题和逐项决策流程有意选择），Distinctiveness 8/10。语义标签、可见焦点、原生 dialog、44px 操作目标及无装饰动效；仍需真实用户评估。

最终真实网页验收：DeepSeek 实际调用到店路线工具，生成四季→中免上葡京(C)→新八佰伴(A)的建议步行顺序，线上B不在路线中，展示多站及分段导航。用户已指定渠道和门店，此测试不证明B的线上价更低。桌面与390px手机无横向溢出，控制台无错误；最终截图和原始验证文字位于忽略的.runtime目录。真实Search→Fetch→双语JSON也已独立跑通。当前新UI仍仅本机。
