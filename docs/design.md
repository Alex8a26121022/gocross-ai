# 商品搜索与比价界面

面向珠澳购物消费者，主操作是文字搜索或上传图片，查看已获取最低价与渠道。保留现有 GoCross 标识、绿色主色和灰白背景，减少首屏解释文字。

桌面主区为搜索表单和商品卡，右侧保留门店地图；窄屏先商品后地图。卡片只展示图、品名/规格、一个报价、渠道和购买链接；小入口「比价详情」打开原生 dialog，包含各平台查询状态、SKU、时间与折叠价格说明/汇率。

主色 #0f766e，背景 #f8fafc，白色内容面；系统中文无衬线、等宽数字，圆角 6/10px，间距 8/12/16/24/32px。无装饰渐变、营销横幅、假指标或执行流水，无商品图时仅用文字占位。

单来源叫最近采集价，多来源同规格才叫已采集报价中最低；国内报价有效期 24 小时，中免报价两分钟，无有效报价不回退模拟数据。上传即识别，发送至智谱的说明紧邻入口，无确认门槛。

验收应覆盖键盘、弹窗焦点/关闭、390px 无横向溢出、桌面卡片和地图、上传成功/失败、空结果、刷新和过期价。自动测试与真实网页验证分别记入当日日志，旧截图不能作为新版本通过证据。
